# Bildunterschriften

Beim Speichern von Abbildungen wird eine kurze Beschreibung in einer
Textdatei abgelegt. Die Hilfsfunktion
`FIT_python.caption_utils.save_caption` erstellt automatisch eine
`.txt`-Datei mit dem gleichen Namen wie die Grafik. Dadurch liegt zu
`results/figures/mein_plot.png` die Datei
`results/figures/mein_plot.txt` vor. Die Beschriftung wird zudem im
Terminal bzw. Notebook ausgegeben.
