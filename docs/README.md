# FIT Package

## Installation

Follow these steps to set up the project using Conda:

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/FIT_package.git
   cd FIT_package
   ```

2. **Create the Conda environment**

   ```bash
   conda env create -f environment.yml
   ```

3. **Activate the environment**

   ```bash
   conda activate FIT
   ```

That's it! Your environment is now set up with all dependencies and the package installed in editable mode.
