# Pipeline Methodology Overview

This document gives a research-style description of the two main analysis pipelines. It draws on the detailed markdown documentation in this repository. Each section is first presented in English and then in German.

## Sex Classification Pipeline (English)
The sex classification workflow begins with `DataImportWrapper.clean_all()` which loads raw CSV tables from `data/raw`, harmonises column names, and converts numeric fields via `transform_utils.convert_numeric`. The cleaned tables are written to `data/cleaned`.

`SplitWrapper.split_all(as_csv=True)` then groups footprints from the same individual and generates `train`, `test`, and optional `inference` sets per species. Within `split_utils` the function `stratified_individual_split` ensures that all footprints of one individual remain in a single split while keeping the male/female ratio balanced. If folds are required, `_make_folds` draws `NUM_FOLDS` stratified groups so that each fold maintains comparable sex proportions.

Model preparation is handled by `pipeline_wrapper_sex.get_pipeline_steps` which assembles a scikit-learn `Pipeline`. Configurable steps include the `ImputationWrapper` using an iterative random forest imputer, `OutlierCleanerTransformer` (either percentile clipping or z-score winsorising), `FeatureScalerTransformer` ("standard" or "robust"), `DimensionalityReducerTransformer` supporting PCA, UMAP or t-SNE, and `FeatureSelectionTransformer` offering forward selection, random-forest importance, variance thresholding, univariate tests or LASSO.【F:docs/pipeline_sex_methodology.md†L28-L35】 The final step attaches one of the classifiers defined in `models.py` such as logistic regression, SVM or gradient boosting.【F:docs/pipeline_sex_methodology.md†L33-L35】【F:docs/pipeline_wrappers/models.md†L6-L13】

`PipelineWrapper.train()` iterates over species directories in `data/splits` and performs five-fold cross-validation using `cross_val_score(scoring="balanced_accuracy")`. Processing times are measured with `perf_counter` and the resulting balanced accuracies are appended to `results/data/raw_results.csv` alongside the selected features and hyperparameters.【F:docs/pipeline_sex_methodology.md†L37-L46】 After fitting, each configuration is refit on the full training data and stored with `joblib.dump()` in `results/data/sex_models`; the best model per species is mirrored to `sex_models_best` for easy prediction.【F:docs/pipeline_sex_methodology.md†L48-L49】

Reproducibility is promoted by caching intermediate results via `joblib.Memory`, saving split files as Parquet and reusing a global random seed from `config.py`.【F:docs/pipeline_sex_methodology.md†L52-L55】 The recorded metrics can be compared to prior literature on sex classification using gait characteristics, e.g. Hotelling (1933) for PCA and Tibshirani (1996) for LASSO.

## Methodik: Sex-Klassifikations-Pipeline (Deutsch)
Der Ablauf startet mit `DataImportWrapper.clean_all()`, das die Rohdaten aus `data/raw` einliest, Spaltennamen vereinheitlicht und numerische Felder über `transform_utils.convert_numeric` aufbereitet. Die bereinigten Tabellen landen in `data/cleaned`.

Im nächsten Schritt erzeugt `SplitWrapper.split_all(as_csv=True)` pro Tierart Ordner mit den Dateien `train`, `test` und optional `inference`. `stratified_individual_split` achtet darauf, dass alle Spuren eines Individuums in demselben Split bleiben, während die Geschlechterverteilung stabil bleibt. Werden Folds benötigt, erstellt `_make_folds` gruppierte Folds gemäß `NUM_FOLDS`.

Die Funktion `get_pipeline_steps` baut eine scikit-learn-Pipeline aus mehreren Bausteinen: `ImputationWrapper` (IterativeImputer auf Basis eines Random Forests), `OutlierCleanerTransformer` zum Clippen oder Winsorisieren, `FeatureScalerTransformer` mit Standard- oder Robust-Skalierung, `DimensionalityReducerTransformer` für PCA, UMAP oder t-SNE sowie `FeatureSelectionTransformer` für Forward Selection, Random-Forest-Importance, Varianzfilter, univariate Tests oder Lasso. Den Abschluss bildet ein Klassifikator aus `models.py` wie logistische Regression, SVM oder Gradient Boosting.【F:docs/pipeline_sex_methodology.md†L28-L35】【F:docs/pipeline_wrappers/models.md†L6-L13】

`PipelineWrapper.train()` führt für jede Tierart eine fünfmalige Kreuzvalidierung mit Balanced Accuracy durch und protokolliert die Laufzeiten mit `perf_counter`. Die Ergebnisse inklusive ausgewählter Features werden in `results/data/raw_results.csv` abgelegt. Anschließend werden alle Modelle auf den gesamten Trainingsdaten erneut trainiert und per `joblib.dump()` in `results/data/sex_models` gespeichert; das jeweils beste Modell pro Art wird zusätzlich nach `sex_models_best` kopiert.【F:docs/pipeline_sex_methodology.md†L37-L49】

Reproduzierbarkeit entsteht durch zwischengespeicherte Zwischenergebnisse (`joblib.Memory`), das Abspeichern der Splits im Parquet-Format und einen global festgelegten Zufallssamen in `config.py`.【F:docs/pipeline_sex_methodology.md†L52-L55】 Die Methode orientiert sich an Verfahren wie PCA (Hotelling, 1933) und der Lasso-Regression (Tibshirani, 1996).

## Pairwise Individual Identification Pipeline (English)
This workflow tests whether two movement trails originate from the same individual. `generate_pairwise_comparisons_from_df` can consume predefined trail pools or draw diverse random subsets for each animal. It forms cross- and within-individual pairs, labels them with `same_individual` and assigns folds on the individual level (stratified by sex). Parameters such as the window lengths control the number and length of trails.【F:docs/pairwise_individual_id_pipeline.md†L9-L16】

`compute_distances` returns multiple distance measures including Euclidean, Manhattan, cosine, Chebyshev, Canberra and Bray‑Curtis.【F:docs/pairwise_individual_id_pipeline.md†L23-L34】 These metrics allow comparison of both global and local shape differences between trails.

The heart of the process is `run_all_pairwise_projections_parallel`. For each pair it applies optional outlier cleaning (`OutlierCleanerTransformer`), feature scaling (`FeatureScalerTransformer`), forward feature selection via `FeatureSelectionTransformer(method=selection_method, k=k_max)`, then dimensionality reduction with LDA, PCA or UMAP using `DimensionalityReducerTransformer(method=reducer, n_components=n_components)`. Distances are computed between the projected centroids and summarised with mean and median values across all individual points.【F:docs/pairwise_individual_id_pipeline.md†L41-L55】【F:src/FIT_python/pipeline_individual_id/pairwise_individual_id_pipeline.py†L232-L318】

Each pair is processed by `process_pair` and the computation can be parallelised using `joblib.Parallel` with progress reporting from `tqdm_joblib`. The resulting dictionaries record all parameters (pipeline name, selected features, component counts), the distance metrics, the predicted sex probabilities if provided and the projected coordinates for both trails and the reference RCV set.【F:docs/pairwise_individual_id_pipeline.md†L61-L69】【F:src/FIT_python/pipeline_individual_id/pairwise_individual_id_pipeline.py†L363-L370】

## Methodik: Pairwise-Identifikations-Pipeline (Deutsch)
Diese Pipeline untersucht, ob zwei Bewegungssequenzen vom selben Tier stammen. `generate_pairwise_comparisons_from_df` kann vorgegebene Trails verwenden oder vielfältige Zufallsteilsets ziehen. Anschließend werden Paare verschiedener Längen gebildet und mit einem Flag `same_individual` versehen. Die Zuweisung zu Folds erfolgt personenweise mittels `StratifiedKFold` über das Geschlecht; nur Paare aus demselben Fold bleiben erhalten.【F:docs/pairwise_individual_id_pipeline.md†L9-L16】

`compute_distances` berechnet für jedes Paar mehrere Distanzen wie euklidisch, Manhattan, Cosinus, Chebyshev, Canberra und Bray‑Curtis.【F:docs/pairwise_individual_id_pipeline.md†L23-L34】 So lassen sich unterschiedliche Aspekte der Ähnlichkeit erfassen.

Anschließend durchläuft `run_all_pairwise_projections_parallel` Kombinationen von Outlier-Methoden (`OutlierCleanerTransformer`), Skalierungsverfahren (`FeatureScalerTransformer`), Feature-Selektion (`FeatureSelectionTransformer`) und Dimensionsreduktion (`DimensionalityReducerTransformer`). Für jede Variante werden die Trails in einen gemeinsamen Raum projiziert, die Distanzmetriken berechnet und statistische Kennwerte wie Mittel- und Medianabstände erfasst.【F:docs/pairwise_individual_id_pipeline.md†L41-L55】【F:src/FIT_python/pipeline_individual_id/pairwise_individual_id_pipeline.py†L232-L318】

Die Verarbeitung einzelner Paare übernimmt `process_pair`; durch `joblib.Parallel` lässt sich der gesamte Vorgang verteilen und mittels `tqdm_joblib` der Fortschritt anzeigen. Das Ergebnis enthält sämtliche Hyperparameter, die berechneten Distanzen, gegebenenfalls Sex-Wahrscheinlichkeiten und die Koordinaten der projizierten Trails samt RCV-Referenz.【F:docs/pairwise_individual_id_pipeline.md†L61-L69】【F:src/FIT_python/pipeline_individual_id/pairwise_individual_id_pipeline.py†L363-L370】
